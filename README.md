# web-problema-semaforos

Proyecto en **React + TypeScript** con **Arquitectura Hexagonal + DDD (Domain-Driven Design) + Diseño Modular + Carpeta `shared` + Atomic Design (Smart & Dumb Components)** que documenta y simula la problemática semafórica en el Norte y Oriente de Santiago de Cali (UNIAJC) y la propuesta de solución mediante **Arduino, Luces LED, Paneles Solares y Administración Centralizada por Zonas Independientes**.
